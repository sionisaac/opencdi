# OpenCDi v0.2.1

- Added automatic disc-folder rescanning and missing-media downloads.
- Removed Download Artwork and Rescan Library from Paths and removed the Refresh toolbar button.
- Moved Settings to the former Refresh position and added About with the project description, credits, and app version.
- Updated the library to show covers without surrounding boxes, with a 10-by-4 grid at the smallest size.
- Added disc logos below covers when available, with disc titles as a fallback.
- Added custom missing-cover and missing-disc placeholder images.
- Added a working library search bar with live filtering and keyboard shortcuts.
- Added synopsis downloads saved as per-disc text files in Portable/Synopses or %APPDATA%/OpenCDi/Synopses.
- Redesigned the loading and Info screen with a centred spinning disc, logo or title at the top, 3D box art at the upper left, back cover at the lower left, and synopsis on the right.
- Removed the loading message and duplicate disc title when a logo is available.
- Updated the pause screen with centred headings, logo support, and Info in place of Resume. Info opens the disc artwork and synopsis screen.
- Added navigation back to the previous screen with the configured CD-i Button II, including Info, Controller Settings, and About.
- Changed the controller screen's navigation label to Back.
- Added Play Disc to the toolbar when Windows detects a readable disc in a connected optical drive.
- Added Missing Media.txt beside the executable, grouping missing artwork and synopses by disc and refreshing as downloads arrive.
- Added startup checks for newer stable GitHub releases, with an optional verified download and restart.
- Tweaked artwork lookup.

The Windows package is OpenCDi-Windows-x64.zip. Extract it and run opencdi.exe.
For an existing installation, close OpenCDi and replace opencdi.exe.

The automatic updater uses stable numeric release tags and the Windows ZIP asset.
It keeps a backup of the previous executable in an .opencdi-update-* folder.
Physical disc playback depends on the connected drive being able to read the disc.
